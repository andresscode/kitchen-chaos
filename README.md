## About

This repo is a learning sandbox, not a production game. The goal is to practice core Unity workflows — scenes, prefabs, the new Input System, and URP — by following along with a tutorial.

## Tech Stack

| Package | Version |
|---|---|

| Universal Render Pipeline | 17.5.0 |
| Input System | 1.20.0 |
| AI Navigation | 2.0.14 |
| Timeline | 1.8.12 |
| Test Framework | 1.7.0 |

## Getting Started

1. Install Unity Hub and Unity `6000.5.8f1`.
2. Clone this repo and open it as a project in Unity Hub.
3. Open the main scene under `Assets/Scenes`.

## Tests

Run tests via **Window > General > Test Runner** in the Unity Editor.
